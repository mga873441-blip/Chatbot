# Chatbots Profesionales - Landing Page

## Descripción
Esta es una **página web profesional** diseñada para ofrecer servicios de chatbots personalizados. La web está creada en **HTML y CSS**, con diseño moderno, efectos de **parallax**, animaciones suaves, iconos y un layout **responsive**, ideal para mostrar en **Fiverr** o como landing page de negocios.  

Con esta web podrás presentar tus servicios de:
- Chatbots para páginas web.
- Chatbots para WhatsApp.
- Chatbots inteligentes con IA.

Incluye secciones de:
- Servicios
- Beneficios
- Testimonios
- Planes y precios
- Contacto
- Footer profesional

---

## Tecnologías utilizadas
- HTML5
- CSS3
- Font Awesome para iconos
- Animaciones CSS y efectos hover
- Diseño **responsive** para móviles y tabletas

---

## Cómo usar esta web
1. **Descarga los archivos** del proyecto:
   - `index.html`  
   - `style.css` (si los separaste)
2. **Editar la información**:
   - Cambia los textos de servicios, beneficios, precios y testimonios.
   - Reemplaza `tuemail@ejemplo.com` por tu correo real.
3. **Abrir la web localmente**:
   - Abre `index.html` en tu navegador.
4. **Publicar online**:
   - Puedes usar servicios gratuitos como [GitHub Pages](https://pages.github.com/), [Netlify](https://www.netlify.com/) o [Vercel](https://vercel.com/).
